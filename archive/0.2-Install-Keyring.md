1. **Remove the Current Key File**:
   First, remove the existing key file that's causing the warning.
   ```bash
   sudo rm /etc/apt/trusted.gpg.d/docker.gpg
   ```

   ```bash
   curl -fsSL https://download.docker.com/linux/ubuntu/gpg | gpg --dearmor -o docker.gpg
   sudo mv docker.gpg /etc/apt/trusted.gpg.d/
   ```

   The `gpg --dearmor` command converts the key from ASCII armor format (text) to the binary format that `apt` expects.

3. **Update Your Package Lists**:
   After adding the key in the correct format, update your package lists.
   ```bash
   sudo apt-get update
   ```
